# Sabbir Hosen Akash — Writarion Portfolio

A responsive personal portfolio focused on autonomous AI development, web design and development, SEO, Google Knowledge Panel support, graphic design and social media services.

## Main sections

- **Hero:** concise professional positioning and direct project enquiry actions.
- **Services:** six animated service cards with a center-logo reveal, docking transition, title/description typewriter sequence and repeat loop.
- **About:** professional introduction and Prilina AI overview.
- **Expertise:** AI, web, SEO, design, social media and communication capabilities.
- **Selected work:** Prilina, Knowledge Panel/entity support, Meetwoyou and selected digital projects.
- **Credentials:** education, leadership, publications and creative background.
- **Contact:** email, WhatsApp and enquiry form.
- **CV:** print-ready A4 layout at [cv.html](./cv.html), with Print / Save as PDF.

## Files

- `index.html` — portfolio structure, metadata and Person structured data
- `style.css` — responsive visual system and animation styling
- `script.js` — interactions, service-card sequence, contact form and install prompt
- `cv.html` — professional CV
- `sw.js` — service worker and cache refresh

## Deployment

The site is built as a static website and can be hosted with GitHub Pages. In the repository settings, enable Pages for the `main` branch and the root folder. For a project site, the expected URL is:

`https://sabbirhosenakash.github.io/DJ/`

The service-card animation is independent of AOS scroll transforms. It pauses when a card leaves the viewport and respects the visitor's reduced-motion preference.
